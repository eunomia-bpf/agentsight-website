Quick start guide

Getting started with AgentSight

Begin with one representative local run. Keep the raw database private, export only what you intend to review, and use the current AgentSight README when command behavior changes.

  • ✓Install the released CLI.
  • ✓Record one selected command.
  • ✓Open or export the resulting profile.

Record the smallest useful run

Choose a task with a clear start and end. Run AgentSight around the agent command instead of enabling broad background capture, then confirm the session database and report can be read.

Handle the result as sensitive data

A captured session can include prompts, responses, paths, headers, and network targets. Review and redact before attaching an export to an issue or pull request.

● Terminal
$ cargo install agentsight
$ sudo agentsight record -- claude
$ agentsight report export -o snapshot.json
