From an agent trace to a review artifact

Raw traces are evidence stores, not review documents. A useful artifact selects the paths relevant to a decision and preserves links back to the underlying run.

  • ✓Define the review question before summarizing.
  • ✓Keep claims traceable to commands and effects.
  • ✓Redact sensitive session material before sharing.

Reduce by decision relevance

For a pull request, keep commands, test outcomes, retries, and file scope. For an extension audit, keep child processes, external paths, remote destinations, and unexplained privileges. Do not summarize every event equally.

Preserve uncertainty and provenance

Mark effects whose purpose is inferred, distinguish missing capture from confirmed absence, and retain enough session identifiers or timestamps for a trusted reviewer to return to the original evidence.
