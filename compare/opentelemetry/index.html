AgentSight and OpenTelemetry

OpenTelemetry is a vendor-neutral toolkit for generating, collecting, and exporting telemetry. AgentSight is a profiler for agent intent and system effects that can also export captured LLM calls as OTel GenAI spans.

  • ✓Keep OTel as the shared telemetry pipeline.
  • ✓Use AgentSight to collect agent-specific system evidence.
  • ✓Export compatible spans where correlation helps.

OpenTelemetry is broader infrastructure

OTel defines APIs, SDKs, collectors, signals, and semantic conventions. It is not itself an observability backend. AgentSight is a concrete profiling product with a narrower agent-run workflow.

AgentSight can feed an existing OTel environment

Use AgentSight where eBPF and local session parsing add evidence that normal instrumentation misses, then export supported LLM activity into the OTel pipeline rather than replacing it.
