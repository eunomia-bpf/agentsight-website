Claude Code observability

Claude Code observability from the system boundary

Claude Code logs can describe conversation state. AgentSight adds a process-centered view of what executed on the machine during the selected run.

  • ✓See child commands and exit status.
  • ✓Attribute file and network effects.
  • ✓Keep capture local by default.

Observe what the agent caused

Record the Claude command, then connect prompt and tool phases to the process tree, repository activity, network destinations, and resource samples available in the run.

Use evidence for debugging and review

A bounded profile helps explain a slow session, a failing tool loop, an unexpected path access, or the execution history behind an AI-generated patch.

● Terminal
$ sudo agentsight record -- claude
