Claude Code integration

AgentSight for Claude Code

Use Claude Code normally while AgentSight records the selected process family. No Claude-specific SDK or model proxy is required for the core system profile.

  • ✓Keep the native Claude Code workflow.
  • ✓Inspect process and file effects.
  • ✓Create a local review artifact.

Start with the maintained record command

Agent runtimes and packaging change. Use the current AgentSight agent guide for the supported discovery and binary-path behavior rather than copying an old attachment recipe.

Review local data carefully

Claude sessions and AgentSight databases may contain prompts, responses, repository paths, headers, and network targets. Keep raw data local unless you intentionally export it.

● Terminal
$ sudo agentsight record -- claude
